# 航运数字孪生

这个仓库收录两个浏览器端港口案例。可以在《潮汐港》中查看三维港区，也可以在梅山港案例中调整靠泊安排，观察两艘船何时开始候位、何时进场，以及会船时相隔多远。

## 梅山港三维靠泊推演台

以 2026 年 9 月 17 日宁波舟山港梅山 9 号泊位的两船交接为例，使用 1,172 条 AIS 报文回放历史船位。切换到“条件推演”，可以调整前船延误、交接预留和后船到达策略，比较靠泊时刻、位前等候时长与两船模型净距。[中文使用说明](./examples/meishan-berth-3d/README.md) · [离线推演台 HTML](./examples/meishan-berth-3d/梅山港_三维靠泊推演.html)

在 HTML 的 GitHub 文件页点击 **Download raw file**，保存后用 Chrome 或 Edge 打开即可离线运行。保留默认条件，点击时间线下的 **两船最近 14:22:03**，可以直接查看两船模型外沿相距约 85 米时的画面。
