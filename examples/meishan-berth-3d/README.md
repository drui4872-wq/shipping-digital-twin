# 梅山港三维靠泊推演台

如果长顺轮晚两个小时离开梅山 9 号泊位，长行轮什么时候可以进场？这个单文件网页以 2026 年 9 月 17 日宁波舟山港梅山岛国际集装箱码头的两船交接为例，用 1,172 条 AIS 报文回放历史船位，并在同一片水域比较不同到达安排下的等候时长、靠泊时刻和两船净距。页面时间均为北京时间。

## 本地打开

在 GitHub 打开 [梅山港_三维靠泊推演.html](./梅山港_三维靠泊推演.html)，点击文件工具栏的 **Download raw file** 下载原文件，再用 Chrome 或 Edge 打开。网页已内置渲染引擎、卫星底图和船位数据，可直接离线运行。三维场景支持拖动旋转、滚轮缩放和单船跟随，也可切换到卫星俯视图。

## 试跑一次交接

1. 打开 **条件推演**，保留默认的“共用一个作业位”“前船延误 120 分钟”“交接预留 15 分钟”和“按原安排”。长顺轮于 14:17 释放作业位，长行轮于 14:20 结束候位，14:48 靠泊。
2. 点击时间线下的 **两船最近 14:22:03**，查看会船时的相对位置。默认方案下，两船模型外沿最近约 85 米。
3. 切换到 **协同晚到**。在同样的泊位条件下，长行轮仍于 14:48 靠泊，位前等候由 96 分钟降为 0。可用 **导出方案** 保存参数和结果，也可切回 **历史回放** 核对当日 AIS 报位。

## 如何理解结果

历史回放可以逐条查看报位，也可以在相邻报文间插值。条件推演沿当日航迹调整进出港时序，同时检查泊位可用时间和两船转向时占用的水面。每艘示意船体用随船艏旋转的 340 米 × 50 米矩形包住，矩形外沿之间预留至少 50 米。该距离是本例的建模参数，真实船舶尺度、实际解缆时刻和通航间距仍需现场数据核实。

轨迹来自调度宝，卫星底图使用 Copernicus Sentinel-2 影像。三维场景使用 Three.js，船体、码头构件与海面改编自《潮汐港》，环境光来自 Poly Haven。页面内的 **数据与假设** 列有原始轨迹文件的校验值、观测时间窗和资源来源。
